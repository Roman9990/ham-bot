# 🤬 Вася — матерный бот-приколист на Ollama

Умный хам: сначала стёб, потом по делу. Помнит контекст, сам доебывается если чат молчит.

## Что умеет
- Отвечает на **любое сообщение** через Ollama (в личке всегда, в группе — реплай/тег/триггер или 15% рандом)
- Режимы дерзости: `/mode light` (мягко), `/mode zhest` (стандарт), `/mode max` (конченый блядина)
- Фан: `/roast`, `/diss`, `/anekdot`, `/klichka`, `/mudrost`, `/hvala`
- Память последних 20 сообщений: `/reset` чтобы забыть
- Проактив: сам пишет в молчащие чаты раз в N минут
- Если просят серьёзное (код, учёба) — сначала подъебнёт, потом нормально ответит

## Установка

1. Поставь Ollama: https://ollama.com/download
2. Скачай модель с хорошим русским:
```bash
ollama serve
ollama pull qwen2.5:7b
# альтернативы: llama3.1:8b, mistral-nemo, gemma2:9b
```
3. Создай бота у @BotFather, забери токен
4. Настрой:
```bash
cd ham-bot
cp .env.example .env
# вставь BOT_TOKEN, при желании поменяй OLLAMA_MODEL / HAM_MODE
pip install -r requirements.txt
python bot.py
```

## Настройки .env
- `OLLAMA_URL` — по дефолту http://localhost:11434
- `OLLAMA_MODEL` — qwen2.5:7b лучше всего для русского мата
- `HAM_MODE` — light|zhest|max
- `TRIGGER_CHANCE` — 0.15 как часто отвечать в группе без тега
- `PROACTIVE_ENABLED` — true/false, сам ли пишет
- `PROACTIVE_INTERVAL_MIN` — 45 минут молчания
- `MEMORY_LEN` — 20 сообщений памяти
